# Climate Attention Atlas — Project One-Pager

## What the project sets out to do

Climate Attention Atlas investigates how events relate to changes in attention to issues relevant to T&E. The current prototype uses major wildfires and floods as test events, and **climate change and electric vehicles as test topics**, to demonstrate the approach. These initial search phrases are a proof of concept, not a final or fully validated definition of T&E's interests. Its central design choice is to measure events independently from the media response: disasters come from external hazard catalogues, while attention is measured from news publishing data. The result is a reproducible data pipeline and interactive research interface for exploring when attention rises, where it rises, whether it persists after an event, and how much of the coverage includes political actors or government action.

The project is intended as an exploratory research platform, not yet as proof that extreme-weather events cause changes in news coverage or public opinion.

## Data sources

- **GDELT Web NGrams 3.0** is the current MVP's primary attention source. It provides distinct matched news URLs by UTC day, topic, and publishing-outlet country. The pipeline also supports the GDELT DOC API as a comparison and validation source.
- **GDACS (Global Disaster Alert and Coordination System)** supplies named wildfire and flood events, dates, affected countries, alert levels, locations, and provider-reported severity. Orange and Red alerts form the main analytical cohort.
- **NASA MODIS** supplies country-level burned-area observations and seasonal NDVI anomalies, allowing media attention to be viewed alongside physical burning and surface greenness or browning.
- **NASA FIRMS** provides an additional physical wildfire layer based on science-quality VIIRS detections and fire radiative power. It is kept distinct from named GDACS events and from burned area.
- **Natural Earth** boundary data supports reproducible country assignment and map labels. An unofficial Google Trends collector is available as a search-interest fallback, but its independently scaled and unstable data are not used as the main outcome.

## Methodology in brief

The two test topics use configurable phrase lists: for example, “climate change”, “global warming”, and “climate crisis”, or “electric vehicle” and “electric car”. The current Web NGrams pipeline searches **original-language text using preconfigured translations and local equivalents**; it does not automatically translate each article. The seed lists cover ten languages, with non-English entries still marked as drafts. Local terminology, plurals, ambiguous words, and writing systems can affect what is found. The alternative GDELT DOC API instead searches English terms over machine-translated coverage, so the two methods need separate checks.

Verification means native speakers reviewing the phrases and sampled articles in each priority language and market: **precision** asks how many matches are relevant, while **recall** asks how much relevant coverage is missed, using an independently reviewed sample that also includes articles the search did not match. Reviewers would also check political labels, resolve disagreements, and test revised lists on a separate sample. This validation is planned; working software and translation-status labels do not establish classifier accuracy. T&E can help select the topics, markets, and local terminology to validate first.

Within each topic, matching phrases are alternatives and every URL is counted at most once per topic and day. Media geography means the country of the publishing outlet—not the event location, article subject, or audience. Political coverage is a deduplicated union of political-actor, government-action, party-politics, and known official-domain signals.

For each GDACS event, the system compares mean daily URL counts during an event-onset window, or during a post-event persistence window, with the event's own immediately preceding baseline. Users can select 7-, 14-, or 28-day windows and compare affected countries, other EU countries, the rest of the world, or the global total. Pooled results use the median event response and show the interquartile range. Every required date must be present; missing days are never filled with zero, the confirmed 14 June–1 July 2025 GDELT outage is excluded, and overlapping major events in the same country are excluded by default.

These before-and-after estimates and lead/lag correlations are descriptive associations. They do not yet control for seasonality, concurrent news, autocorrelation, or an untreated comparison group.

## What the interface tabs do

- **Explore** maps individual floods and wildfires. Selecting an event opens an **Attention** tab with daily climate-change and EV coverage plus a before/after test, and a **Coverage breakdown** tab showing timing, political signals, and the largest publishing markets.
- **Analysis Lab — Event study** pools comparable events and tests different hazards, media groups, time windows, and definitions of attention. It reports the median response, variation across events, country patterns, and the events with the largest increases.
- **Wildfire attention** ranks which fires generated the strongest response and compares attention with GDACS-reported area. Its severity residual is a descriptive benchmark, not a forecast.
- **Event activity** compares rolling event starts with attention over time and offers exploratory lead/lag correlations and country comparisons.
- **Attention timeline** provides the broad time-series view across topics and publishing markets, with event markers and optional GDACS burned area, MODIS burned area, and NDVI overlays.
- **Data** documents current coverage, gaps, and source provenance; **Methods** records the definitions, design choices, limitations, and validation protocol.

## How successful is it?

The project is successful as an end-to-end MVP. As of the 10 September 2026 corrected analysis export, it contains **230,884 daily topic-market rows** covering **586 observed news days and 197 configured publishing markets (182 with mapping support)**, **531,101 retained article records**, **9,024 GDACS wildfire and flood events**, and **112,410 MODIS observations** across 199 geographies. The major-event exports include 40 events for 2025 and 23 for 2026, with 2,416 complete event/specification rows available across the two studies. The map explorer, attention timeline, event drill-downs, multi-event Analysis Lab, satellite comparisons, resumable collection, provenance records, and Supabase aggregate serving layer are all implemented. Supabase is required for the full current interface. On 15 September 2026, the automated suites passed **118 Python tests and 49 frontend tests**; these checks do not validate measurement accuracy.

The early substantive results are promising but not uniform. Under the 14-day, non-overlapping specification, median affected-market climate-change coverage increased around event onset by 9.5% across 16 eligible 2025 events and 29.8% across eight eligible 2026 events. The corresponding global medians were smaller and mixed (+3.0% and −4.6%), while electric-vehicle attention showed no consistent increase.

The descriptive results remain sensitive to window choice and event eligibility. For affected-market climate attention, 7/14/28-day onset medians are 0.0%/+9.5%/+1.9% in 2025 and +1.7%/+29.8%/0.0% in 2026, with different samples at each window. Some large percentage changes have very small URL baselines. The interface now shows window sensitivity instead of a selected-country significance leaderboard and reports observed changes without day-shuffling p-value verdicts.

The September correctness update makes unsupported mappings unavailable, retains observation windows across calendar years, checks Orange/Red overlaps across all years regardless of displayed cohort, and preserves missing dates on event charts. These corrections do not establish causality or validate the classifiers. See [implementation and result changes](docs/IMPROVEMENTS_PHASE1.md), including the verified 10 September serving-table synchronization. Future releases must continue coordinating static exports and remote tables; this is not automatic.

## Future plans

The next phase is to expand both the evidence base and the questions the platform can answer. Priorities are to:

1. **Extend the data backwards** to build a longer historical record, cover more events, and improve the power and robustness of comparisons.
2. **Agree and validate T&E's topic and language coverage, then automate refreshes.** Replace or expand the climate-change and EV test phrases with reviewed topic definitions and local equivalents. Schedule news, search, event, and physical data updates daily, weekly, or monthly as appropriate, with completeness checks, language-coverage checks, and alerts for failed runs.
3. **Add Google Trends as a core comparison source** to measure what people search for, complementing GDELT's measure of what news outlets publish. An unofficial collector exists, but reliable official-API collection is not yet integrated. As of September 2026, the developer's individual access application has been unanswered for around a month; the proposed next step is an application under T&E's name with a concrete research use case. Google still limits access to its [API alpha](https://developers.google.com/search/apis/trends). Integration is expected to be manageable once access is granted, building on the existing pipeline, but requires an official connector and a pilot checking quotas, language/query choices, scaling, and completeness before routine use.
4. **Add public social-posting data from Bluesky and, where access permits, X.** This would measure what people post about and could follow defined groups such as MEPs and other politicians, linking the Atlas to existing T&E political and communications work.
5. **Broaden the event layer beyond extreme weather.** Add temperature departures from local historical norms and more hazard types, alongside a dated register of COP meetings, EV launches, elections, policy announcements, and implementation dates. Each entry would record its source, timing, event type, and relevant countries, allowing the same before/during/after comparisons. A separate geopolitical and energy-market tracker would cover events such as Strait of Hormuz disruptions, conflicts, sanctions, and supply shocks, alongside oil-price series. For example, a predefined crossing of US$100 per barrel in a specified benchmark could test whether EV news, searches, or posts subsequently increase, in which countries, and for how long. These are proposed analyses, not findings.
6. **Test timing and cross-country spillovers.** Examine whether attention rises in country A before country B, how long any lag lasts, and whether patterns differ across news, search, and social posting. Account for shared events, seasonality, and concurrent news before interpreting a sequence as diffusion between countries. Extend comparisons to event severity, geography, and political attention.
7. **Build toward a predictive model of attention from event data.** Once the historical panel and validation are strong enough, use out-of-sample evaluation and interpretable feature-importance methods to identify which event characteristics best predict attention.
8. **Continue validating the approach throughout:** conduct native-speaker and precision/recall reviews of topic and political classifiers; audit domain-to-country attribution; add validated news denominators; compare event sources without treating unlike severity measures as equivalent; pre-register confirmatory hypotheses; add matched dates or untreated markets; and correct for multiple testing.
